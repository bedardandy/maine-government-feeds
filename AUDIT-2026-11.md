# Audit, 2026-11-23

Scope: `sources.yml`, `scripts/`, both workflows, open PRs/branches, pinned
dependencies. Evidence: CI run logs through run 535 (2026-11-23 07:27 UTC),
the committed state in `data/state/`, and an independent code review whose
findings were each reproduced with a probe script or shown in repo data.

## Headline

**Nothing has been published since 2026-10-29.** Every scheduled build for 25
days (about 100 runs) failed at validation.

1. On 2026-10-15 every request to `www.maine.gov` / `www1.maine.gov` started
   returning HTTP 403. That is 33 of 114 enabled sources: Secretary of State
   (6), Attorney General (3), Governor (3), Revenue (3), agencies (12),
   Workers' Compensation (3), Human Rights Commission (3).
2. Fourteen days later the staleness gate turned those 33 into build-breaking
   errors. Validation runs before the commit step, so the 81 healthy sources
   stopped publishing too, the health state stopped being saved, and the
   source-health issue was never opened (that step also runs after
   validation). No alert fired.

PR #18 (open since 2026-11-17, checks green) makes staleness a warning. This
branch is built on it.

## Needs a decision from the maintainer

1. **Merge the staleness fix** (PR #18, or this branch, which contains it).
   Until then the site stays frozen at October 29.
2. **`maine.gov` 403s.** Not diagnosed: this sandbox cannot reach the host.
   From a normal connection, fetch `https://www.maine.gov/robots.txt` and one
   source URL with the bot's User-Agent. If the block targets the bot or
   GitHub's address ranges, the options are to ask Maine IT to allow the
   identified, robots-honoring monitor, or to accept it and set
   `health_ignore: true` on the 33 sources. Do not rotate the User-Agent or
   proxy around it.
3. **Governor's office URLs.** Three sources point at
   `/governor/mills/…`. Governor-elect Hannah Pingree takes office in January
   2027; expect those paths to change.
4. **133rd Legislature** convenes the first Wednesday of December. The
   hearings feed fix above lands just before it is exercised again; watch the
   first week's output.
5. **Sources worth pruning or repairing**
   - `fed-meb-opinions`: selectors match nothing since 2026-07-18; the
     govinfo and CourtListener feeds cover the same court.
   - `digitalmaine-puc-docs`: newest document is from 2021.
   - `mhrc-decisions`: newest decision listed is from 2020; 24 duplicates
     from a site path rename.
   - `jb-jury-notices`: daily juror call-in instructions; 50 change items

   - `fed-nlrb-news`: nothing new since June; confirm the feed URL.
6. **Housekeeping.** PR #9 is already fixed on `main`; PR #8's `HANDOFF.md`
   describes July's repo (103 sources, classification gated on a key). Eleven

7. **Dependencies.** Patch updates available: `lxml` 6.1.3, `PyYAML` 6.0.4.
   Major updates available and not taken without a live test: `anthropic`

## Known, not fixed

- An upstream URL change mints a duplicate item (id is `hash(link|title)`):
  18 in `fed-scotus-opinions`, 3 in `jb-sjc-opinions`.
- Date-only scraped dates are stamped midnight UTC, which is the previous
  evening in Maine: 282 RSS/Atom entries carry the prior day's date.
- Hearing times are Maine wall-clock values labelled `+00:00` in RSS/JSON
  (the calendar files are correct).
- Completed days in the daily digest can still change after the fact.

## Not verified here

- No source could be fetched from this sandbox. The build changes were
  exercised end to end against the repository's real state with the network
  stubbed, then validated; live behavior needs one CI run.
- The Codex CLI was not run; the watcher's flags follow its documentation.
- The action major versions come from a web search, not the release pages.
- The `fastembed` model could not be downloaded here. That backend's calls
  were checked against the installed package's signatures only; everything
  else in `firm/` is covered by tests.
